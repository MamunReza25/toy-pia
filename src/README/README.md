## 🧠 About ToyPia

**ToyPia** is a vibrant online toy store where kids and parents can explore, discover, and review amazing toys.  
Built with **React**, **Tailwind CSS**, and **Firebase**, it offers smooth performance and a delightful user experience for all ages.

---

## 🌟 Key Features

- 🔐 **Firebase Authentication** – Secure login & logout  
- 👤 **Profile Update** – Edit user info & profile picture  
- 🧩 **Upcoming Toys** – Discover newly added toys  
- 💬 **Customer Feedback** – Read real customer experiences  
- 🎈 **Enjoy Moment Section** – Capture kids’ happy moments  
- 🧸 **Toy Details Page** – Detailed info of every toy  
- 🛍️ **My Toys Page** – Manage user-added toy list  
- 📱 **Responsive Design** – Works perfectly on all devices
